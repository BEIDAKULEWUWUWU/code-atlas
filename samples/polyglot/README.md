# polyglot-sample

A deliberately mixed-language project, used to exercise Code Atlas on something that is not
JavaScript. Every file here is filler — the point is the spread of extensions and sizes.

`misc/telemetry.qqq` is filler too, but on purpose: `.qqq` is not a format, so it lands in 其他 and
keeps that branch exercised. The unknown bucket can never be emptied — no suffix table finishes —
so the sample keeps a file in it.

    npm run scan -- samples/polyglot --out samples/polyglot.json
